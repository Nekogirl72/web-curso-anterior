# Infernofest

## Descripción
Infernofest es una web de tipo landing page para promocionar un festival de música y cultura, con información sobre la programación, patrocinadores, contacto y formularios de registro. La página está desarrollada con HTML5 y CSS3, usando recursos gráficos locales para la identidad visual del evento.

## Cómo abrirla y ejecutarla localmente

1. Abre una terminal dentro de la carpeta del proyecto.
2. Ejecuta:

```dash
http-server
```

Es probable que debas hacer antes npm run build, para compilar el proyecto y después cd dist para localizarte en la carpeta compilada.

3. Entra en esta URL en tu navegador:

```text
http://192.168.1.102:8080
```
